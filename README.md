# Foodly

Cette base de données a été créée dans le cadre d’un exercice de formation pour apprendre à implémenter des bases de données relationnelles avec SQL.

Elle a été réalisée en suivant le cours OpenClassrooms : Implémentez vos bases de données relationnelles avec SQL.

## Contenu de la base de données

La base contient plusieurs tables liées entre elles, notamment :

- aliment
- famille
- lieu
- appareil
- utilisateur
- réduction
- langue
- utilisateur_aliment
- aliment_lieu
- famille_aliment
- utilisateur_appareil

## Fichiers du projet

- `foodly.sql` : script SQL de la base de données

## Objectif

Ce projet permet de pratiquer la modélisation de données, la création de tables, les relations entre tables et l’écriture de requêtes SQL.
